Put brand assets here:

  logo.png              -> used as the small watermark logo on cards (optional)
  Montserrat-Bold.ttf   -> card font. Download from Google Fonts (SIL OFL license),
                           rename to exactly Montserrat-Bold.ttf and drop it here.

If the font is missing, cards fall back to DejaVu/Arial/PIL default automatically,
but Montserrat gives the intended look.
